## The Distinguishing Signal

Every single one of the 23 good notes corrects a **concrete, falsifiable factual claim** — a specific number, a named person's status, a verifiable event, or authenticated/debunked media. The note-worthy signal is:

> **The post asserts something specific and checkable as fact** — a number, a named person's legal/physical status, a media item's provenance, a historical event's date or outcome — and that specific claim is false or materially misleading against a checkable external record.

This is what separates them from true FP cases (satire, opinion, prediction). The gate logic should key on:

1. **Is there a specific, named-entity or numeric assertion presented as established fact?**
2. **Is that assertion falsifiable against a public record, fact-check, official document, or dated media?**

If both are yes → proceed. If the post only expresses a viewpoint/reaction/forecast without asserting a checkable fact → abstain.

### Why each gate misfires if naively implemented:

**Satire gate** — the 5 "maybe" cases all involve ironic/sarcastic *tone* (deadpan captions, parody account bios, rhetorical flourish), but each still contains or transmits a falsifiable factual claim that reached real readers as fact (e.g. 1.8M impressions on the Man Utd post despite the joke bio). A tone-based satire gate would kill these. The safe framing: "does the *post itself* clearly signal non-factual intent *and* does no concrete falsifiable claim circulate as fact to naive readers?" Both conditions must be true to abstain.

**Opinion gate** — the 2 "maybe" cases (Hormuz yuan, Trump 29%) wrap concrete numeric/event claims in editorial commentary. An opinion gate that fires on "editorializing tone" would kill both. The safe framing: "is the post *only* expressing a viewpoint with no underlying factual assertion?" If there is an embedded factual claim (specific number, specific event) that is falsifiable, the editorial wrapper doesn't make it opinion.

**Prediction gate** — the cleanest gate. Zero collateral damage on this sample. Predictions/speculation are temporally forward-looking; all 23 good notes correct claims about past or present facts. A prediction gate keyed on "claims about future events" is safe to implement.

## Recommended Gate Designs

### Satire gate (safe formulation)
Abstain only if **all** of:
- The account bio explicitly signals parody/satire AND
- The tweet text contains no concrete falsifiable factual assertion (specific number, named-person status, event provenance) AND
- A meaningful fraction of readers would not plausibly take the claim as factual

The current naive framing ("could possibly be read as satire") would have 5 maybes → real kill risk.

### Opinion gate (safe formulation)
Abstain only if the post **solely** expresses a viewpoint/reaction with no embedded falsifiable factual claim. If any specific number, identity claim, or verifiable event is asserted as fact, the editorial tone is insufficient to abstain.

### Prediction gate (safe formulation)
Abstain if the post is forward-looking speculation about a future event with no current or historical factual assertion that can be checked. This gate has zero collateral damage on this sample and is the safest to implement broadly.
