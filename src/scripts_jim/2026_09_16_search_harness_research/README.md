# Search and fetch harness research (GOO-166)

Research into how good our own web search and page fetch tooling is, and which
packages, open source projects or hosted APIs could replace or improve parts of
it. Desk research plus prod log statistics; no pipeline code was changed.

- `RESULTS.md`: the write-up, with a ranked list of what to do.
- `prod_stats.md`: web fetch and web search numbers from the last 14 days of
  prod logs, generated by the scripts below.
- `extract.ts`: reads `pipeline_runs` and `everything_pipeline_runs` from prod
  (read only) and writes the raw per-call extracts `raw_*.json`, which are
  gitignored because they are 8 MB.
- `analyze.ts`: turns the raw extracts into `prod_stats.md`, `failing_hosts.json`,
  `fetch_tags.json` and `query_sample.json`.
- `pageSizes.ts`: the size distribution of successfully fetched pages.
- `peekFetch.ts`: prints the web_fetch results of one run, for inspecting a
  suspicious result by eye.

Run from the repo root, for example `bun run src/scripts_jim/2026_09_16_search_harness_research/extract.ts`.
